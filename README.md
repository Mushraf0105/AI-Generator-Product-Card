# AI Product Card Generator

A modern, dynamic React application that automatically generates beautiful, E-Commerce ready product cards complete with AI-generated copy and images based on just a Product Name and Category.

## 🔗 Live Demo
[View Live Site](https://Mushraf0105.github.io/AI-Generator-Product-Card/)

## 🚀 Setup Instructions

1. **Install Dependencies:**
   Run `npm install` in your terminal.
2. **Start the Development Server:**
   Run `npm run dev` and open the provided localhost link in your browser.
3. **API Key:**
   Get a free API key from [Google AI Studio](https://aistudio.google.com/app/apikey) and enter it directly into the app's UI.

## 📖 How It Works (All Scenarios)

The application is built to be extremely robust and handles various user flows and edge cases gracefully.

### Scenario 1: The Happy Path (Successful Generation)
1. The user provides a valid Gemini API Key, a **Product Name** (e.g., "Quantum Sneakers"), and a **Category** (e.g., "Footwear").
2. Upon clicking "Generate Details", the app instantly displays an animated **Skeleton Loader** to keep the user visually engaged.
3. The app securely contacts the **Gemini API** using the `gemini-flash-latest` model to generate a title, description, price, keywords, and an image prompt.
4. The app then dynamically loads an AI-generated image using **Pollinations AI** based on Gemini's prompt.
5. The UI seamlessly transitions from the skeleton loader to a beautiful, glassmorphic Product Card.

### Scenario 2: Form Validation & Missing Inputs
- If the user attempts to generate a card without providing an **API Key**, **Product Name**, or **Category**, the application prevents the request.
- A clean, red alert box instantly appears in the UI letting the user know exactly which fields are missing (e.g., *"Please provide both a product name and category"* or *"Please provide your Gemini API Key"*).

### Scenario 3: API Errors or High Server Demand
- If the user provides an **Invalid API Key**, the app gracefully catches the 400/403 error from Google and displays it to the user.
- **High Demand (503 Error):** Because the free tier of Gemini can experience traffic spikes, Google's servers occasionally reject requests. If this happens, the app safely intercepts the crash and displays: *"This model is currently experiencing high demand. Spikes in demand are usually temporary. Please try again later."* The app remains fully functional and ready for the user to try again.

### Scenario 4: Image Generation Failure (Fallback Mode)
- AI Image generation can sometimes fail due to network timeouts or server limits at Pollinations AI. 
- To ensure the UI never breaks, the `<img />` tag features a built-in `onError` fallback. 
- If the AI image fails to load, it is instantly replaced with a beautiful, dynamic text-based placeholder (using `placehold.co`) that features the product's title on a dark purple background.

## 🤖 Where AI Was Used

This project heavily relies on two distinct AI models working synchronously to generate a complete product card:

### 1. Text Generation (Google Gemini)
- **Where:** We use the `gemini-flash-latest` model to act as our core copywriting engine.
- **How:** When a user inputs a product name and category, the app constructs a prompt asking Gemini to act as an expert marketer. We enforce a strict `responseMimeType: "application/json"` rule so Gemini returns structured data.
- **Result:** The AI autonomously generates the product's `title`, a catchy `description`, a realistic `price`, related `keywords`, and a detailed `imagePrompt` for the photographer.

### 2. Image Generation (Pollinations AI)
- **Where:** We use Pollinations AI for free, on-the-fly text-to-image generation.
- **How:** The app takes the `imagePrompt` generated by Gemini and passes it directly to the Pollinations AI generator via a standard image source URL.
- **Result:** The app dynamically renders a custom, highly specific AI product photograph to match the AI-generated copy.

## 🎨 Design Choices

1. **Modern Premium Aesthetic**: Built with Tailwind CSS, the UI utilizes a sleek, dark-mode gradient theme (`bg-slate-900` to `indigo-950`). This makes the interface feel highly premium, complete with glassmorphism (backdrop-blur) and smooth micro-animations on hover/click.
2. **Dynamic UI States**: 
    - **Skeleton Loader**: Implemented an animated skeleton pulse effect mimicking the exact shape of the product card to keep users visually engaged while the AI text resolves.
    - **Native Image Loading**: The image tag handles its own loading and error states locally, preventing the app from feeling "stuck" on long image generation times.
