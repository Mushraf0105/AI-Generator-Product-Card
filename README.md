# AI Product Card Generator

A modern, dynamic React application that automatically generates beautiful, E-Commerce ready product cards complete with AI-generated copy and images based on just a Product Name and Category.

## 🚀 Setup Instructions

1. **Install Dependencies:**
   Run `npm install` in your terminal.
2. **Configure Environment Variables:**
   Create a `.env` file in the root folder and add your API key:
   `VITE_GEMINI_API_KEY=your_actual_api_key_here`
3. **Start the Development Server:**
   Run `npm run dev` and open the provided localhost link in your browser.

## 🤖 Where AI Was Used

This project heavily relies on two distinct AI models working synchronously to generate a complete product card:

### 1. Text Generation (Google Gemini)
- **Where:** We use the `gemini-flash-latest` model to act as our core copywriting engine.
- **How:** When a user inputs a product name and category, the app constructs a prompt asking Gemini to act as an expert marketer. We enforce a strict `responseMimeType: "application/json"` rule so Gemini returns structured data.
- **Result:** The AI autonomously generates the product's `title`, a catchy `description`, a realistic `price`, related `keywords`, and a detailed `imagePrompt` for the photographer.

### 2. Image Generation (Pollinations AI)
- **Where:** We use Pollinations AI for free, on-the-fly text-to-image generation.
- **How:** The app takes the `imagePrompt` generated by Gemini and passes it directly to the Pollinations AI generator via a native Javascript `Image()` object (to bypass CORS restrictions). 
- **Result:** The app dynamically renders a custom, highly specific AI product photograph to match the AI-generated copy.

## 🎨 Design Choices

1. **Modern Premium Aesthetic**: Built with Tailwind CSS, the UI utilizes a sleek, dark-mode gradient theme (`bg-slate-900` to `indigo-950`). This makes the interface feel highly premium, complete with glassmorphism (backdrop-blur) and smooth micro-animations on hover/click.
2. **Dynamic UI States**: 
    - **Skeleton Loader**: Implemented an animated skeleton pulse effect mimicking the exact shape of the product card to keep users visually engaged while the AI text resolves.
    - **Asynchronous Image Loading**: A dedicated "Generating photo..." spinner ensures users aren't staring at a blank space while the heavy AI image processes.
3. **Robust Fallbacks**: Designed a failsafe system where if the AI image generator times out due to network issues, a clean text-based placeholder (using `placehold.co`) elegantly takes its place so the UI never breaks.
